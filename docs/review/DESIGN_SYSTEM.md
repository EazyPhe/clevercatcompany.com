# Accepted design system — mechanical lion

The current visual direction is defined by the supplied handoff in
`docs/brand/clevercat-brand-handoff/`. The earlier purple concept set in
`docs/review/concepts/` is retained as historical review material only and is
not the active design direction.

## Visual direction

- **Color lock:** obsidian `#050608`, graphite `#15191D`, gunmetal
  `#343A40`, machined steel `#9CA5AE`, precision white `#F3F6F8`, electric
  blue `#0077FF`, and technical blue `#103C67`. The page background is dark;
  no purple UI identity remains.
- **Typography:** locally bundled `Space Grotesk Variable` for headings and
  UI chrome, plus `Inter Variable` for body copy. The packages are deliberate
  production dependencies so the declared font families are actually loaded.
- **Geometry:** crisp 5 px control corners, restrained ruled panels, thin
  circuit/datum lines, and blue technical accents. There are no fake system
  metrics, status controls, binary strings, or decorative gear animation.
- **Brand and media:** the supplied raster mechanical-lion mark and hero are
  authoritative. The company name and `Engineered to Lead` are real HTML text,
  not lettering sliced from a reference board. The hero remains untinted in a
  black artwork region; linework sits beside it rather than over it.
- **Motion:** subtle link/panel lifts only, disabled by the reduced-motion
  media query.

## Component inventory

- Responsive local-WebP lion lockup in the header and footer, with a visible
  desktop contact CTA and native keyboard-accessible mobile `<details>` menu.
- Responsive lion hero using `srcset`, live discipline line, approved headline,
  approved support copy, two working route CTAs, and the signature tagline.
- Four factual capability groups with matching local technical line icons.
- Rebranded page heroes, work placeholders, process rail, contact CTA, and
  footer; existing factual content and launch safeguards remain unchanged.
- Local favicon/Apple-touch-icon references and an existing lion image as the
  social-preview source. No dedicated social-preview artwork is claimed.
