# Accepted design system

This implementation is based on the original Image Gen concept set in `docs/review/concepts/`.

## Visual direction

- **Color lock:** near-black `#0B0B0F` background, graphite `#17171E` surfaces, white `#F7F7FA` type, muted cool gray copy, and electric purple `#A45CFF` accents. No warm white or cream surfaces are used.
- **Typography:** a clean system sans for navigation, hero, labels, and controls; a restrained system serif only for selected lower-page display headings.
- **Geometry:** open editorial bands, thin rules, modestly square buttons, no default rounded-card grid, and purple line/rail motifs.
- **Brand and media:** original line-drawn cat mark plus original local black-and-violet sculpture and material studies. The hero sculpture is not tinted or covered by an overlay; the violet halo sits behind it.
- **Motion:** brief link/image lift transitions only, disabled by the reduced-motion media query.

## Component inventory

- Header with primary navigation and native, keyboard-accessible `<details>` mobile menu.
- Primary purple CTA, secondary underlined text link, and email fallback link.
- Editorial capability list, material-image work slots, four-step process rail, contact CTA, and structured footer.
- Shared interior-page hero and semantic content bands.

## First-viewport copy lock

The allowed visible copy above the fold of the home page is:

1. `Clever Cat Company`
2. `Work`, `Capabilities`, `About`, `Contact`
3. `Clever solutions. Real results.`
4. `We turn ideas into practical digital, design, engineering, and creative outcomes.`
5. `Start a conversation`
6. `Explore capabilities`

No eyebrow, badge, fake proof, metric, client logo, rating, award, testimonial, or additional hero label is added.
